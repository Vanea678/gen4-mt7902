MediaTek MT7902 WiFi Driver for Arch Linux
Це робоче рішення для виправлення проблеми з бездротовим модулем MediaTek MT7902 (Filogic 310) на ноутбуках Asus Vivobook та інших пристроях, де цей адаптер не розпізнається системою ("UNCLAIMED").

📋 Проблема
Стандартні ядра Linux (навіть 6.19+) часто не містять вбудованого модуля mt7902e, через що мережевий інтерфейс wlan0 просто не створюється. Цей репозиторій надає драйвер, адаптований під сучасні версії ядра.

🛠️ Інсталяція (Arch Linux)
1. Підготовка
Встанови заголовки ядра (необхідні для компіляції модуля):

Bash
sudo pacman -S linux-headers base-devel
2. Збірка та встановлення
Bash
git clone https://github.com/Vanea678/gen4-mt7902  # Заміни на свій юзернейм, якщо зробив форк
cd gen4-mt7902
make
sudo make install
3. Активація
Оновіть базу модулів та завантажте драйвер:

Bash
sudo depmod -a
sudo modprobe mt7902
⚠️ Важливо: Kernel Panic
Під час першої ініціалізації драйвера на ядрі 6.19.14 може виникнути Kernel Panic (Fatal exception in interrupt).
Рішення: Просто примусово перезавантажте ноутбук. Після ребуту драйвер працює стабільно, пінг в нормі (~13-15ms).

📊 Результат
Bash
ip link
# wlan0: <BROADCAST,MULTICAST,UP,LOWER_UP> ...
Що ще додати в опис?
Скриншот пінгу: Ти можеш додати те фото з терміналом, де пінг 13 мс. Це найкращий доказ, що драйвер "живий".

Badge: Додай значок Arch Linux вгорі, це завжди додає +10 до вигляду репозиторію.
